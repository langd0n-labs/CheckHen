# Sampling the flock

You cannot weigh every sheep, so you weigh some of them.

- **Random:** every sheep is equally likely to be picked
- **Stratified:** pick from each paddock in proportion to its size
- **Convenience:** whoever is nearest the gate, which is easy and biased

Which one would you trust for the whole farm?
